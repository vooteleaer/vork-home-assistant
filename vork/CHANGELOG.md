# Changelog

## 0.4.0

- The vØrk node v0.4.0 ([release notes](https://github.com/vooteleaer/vork/releases/tag/v0.4.0)): sessions to a service on a device next to you take the direct path alone (storage between two devices on one network is far faster), and your devices tell each other what runs on them.

## 0.3.2

- The vØrk node v0.3.2 ([release notes](https://github.com/vooteleaer/vork/releases/tag/v0.3.2)): sessions no longer get stuck, direct links come back after an address changes, devices that went away show as offline.

## 0.3.1

- The vØrk node v0.3.1 ([release notes](https://github.com/vooteleaer/vork/releases/tag/v0.3.1)): the map of your network moves smoothly.

## 0.3.0

- The vØrk node v0.3.0 ([release notes](https://github.com/vooteleaer/vork/releases/tag/v0.3.0)): a new node starts in the same network as everyone else, the dashboard draws a map of your devices.

## 0.2.1

- A name changed on the dashboard stays after a restart: the add-on's `name` option is given to the node only at the first start and when it is changed.

## 0.2.0

- The vØrk node v0.2.0 ([release notes](https://github.com/vooteleaer/vork/releases/tag/v0.2.0)).
- The dashboard inside Home Assistant (ingress): **Open Web UI** and **Show in sidebar**, signed in by Home Assistant.

## 0.1.0

- First version: the vØrk node v0.1.0 with its interface, its dashboard behind Open Web UI, a UDP port of its own asked of the router, the name from the add-on's options.
