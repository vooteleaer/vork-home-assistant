# Changelog

## 0.6.2

- Your libraries in Home Assistant's media browser: install the **vØrk storage** integration from this repository (HACS), and the add-on offers itself to it. Photos, videos and music play from there, fetched as they're opened; nothing is copied. vØrk storage v0.6.2.

## 0.6.1

- Its page opens in Home Assistant: vØrk storage v0.6.1 lets Home Assistant show it in a frame (it was blocked, `ERR_BLOCKED_BY_RESPONSE`).

## 0.6.0

- The first vØrk storage add-on: vorkd with its store in the add-on's data, on the vØrk add-on's node, and its page in Home Assistant (ingress, the sidebar). vØrk storage v0.6.0 ([release notes](https://github.com/vooteleaer/vork-storage/releases/tag/v0.6.0)).
